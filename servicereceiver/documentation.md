# system_service

## Default Metrics

The following metrics are emitted by default. Each of them can be disabled by applying the following configuration:

```yaml
metrics:
  <metric_name>:
    enabled: false
```

### system.service.state

Current state of the service, as a platform independent integer code.

State codes are the same on every platform: 0 - unknown, 1 - stopped, 2 - starting, 3 - stopping, 4 - running, 5 - paused, 6 - failed.

| Unit | Metric Type | Value Type | Stability |
| ---- | ----------- | ---------- | --------- |
| {state} | Gauge | Int | Alpha |
